# App icon

The pen nib of the title bar (`PEN_NIB`, U+E3AC, from
[Phosphor Icons](https://phosphoricons.com), MIT license) in the accent
colour, on a transparent background.

* `icon.png` – 256 px, the window and taskbar icon (set in `src/main.rs`)
* `icon.ico` – 16–256 px, embedded in the Windows .exe (`build.rs`); sizes up
  to 32 px use the bold weight so the thin strokes stay visible

Both are generated by `make_icon.py` (needs Pillow) from the fonts that ship
with the `egui-phosphor` crate:

```sh
python make_icon.py <egui-phosphor>/res/Phosphor.ttf <egui-phosphor>/res/Phosphor-Bold.ttf
```
